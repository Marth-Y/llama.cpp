# 用户学习偏好

## 核心学习模式

用户偏好 **"理论 → 源码阅读 → 动手实践"** 的三阶段闭环学习模式。

### 模式详解

```
┌─────────────────────────────────────────────────────────────────┐
│  第一阶段：理论学习                                              │
│  - 学习原理、数学推导                                            │
│  - 资源：视频、书籍、博客                                        │
│  - 时间：工作日1-2小时                                           │
├─────────────────────────────────────────────────────────────────┤
│  第二阶段：源码阅读                                              │
│  - 阅读llama.cpp对应实现                                        │
│  - 理解设计哲学、工程取舍                                        │
│  - 时间：周末                                                    │
├─────────────────────────────────────────────────────────────────┤
│  第三阶段：动手实践                                              │
│  - 实现一个简化版小项目                                          │
│  - NCU验证、性能对比                                             │
│  - 输出面试可讲的项目                                            │
│  - 时间：周末                                                    │
└─────────────────────────────────────────────────────────────────┘
```

### 关键特点

1. **知识与实践强绑定**：每学完一个知识模块，必须有一个对应的小项目实践
   - 学完张量知识 → 做张量小项目
   - 学完KV Cache → 做KV Cache小项目
   - 学完Bank Conflict/Swizzle → 做GEMM矩阵乘优化
   - 学完FlashAttention → 做FlashAttention小项目
   - 学完量化 → 做量化实践

2. **以llama.cpp为参考**：源码阅读阶段以llama.cpp为主，理解工业级实现

3. **项目驱动**：最终整合成一个完整的"Tiny LLM Inference Engine"项目

4. **不喜欢纯论文学习**：用户明确表示不爱看论文，偏好书籍、视频、代码实践

### 学习资源偏好

- ✅ 书籍
- ✅ 视频/课程
- ✅ 代码实践
- ✅ 源码阅读
- ❌ 论文（不喜欢）

### 时间安排

- 工作日：每天1-2小时（零碎时间，理论学习为主）
- 周末：全天（源码阅读 + 动手实践）

### 项目偏好

- 偏好实现**简化版**的核心功能，而非完整复现
- 每个项目都要有**可验证的产出**（NCU分析、性能对比、代码）
- 项目最终要能**整合**成一个可展示的系统

## 学习背景

- 工作经验：3年半C++开发
- CUDA基础：学过语法，需要加强优化实践
- 大模型：了解Transformer、KV Cache原理
- 目标：AI Infra岗位（推理优化、CUDA算子开发）
- 准备时间：3-4个月
